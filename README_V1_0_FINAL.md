# Ψυκτικός — v1.0 FINAL

Τελική οργανωμένη έκδοση του project της εφαρμογής «Ψυκτικός».

## Περιλαμβάνει
- Κεντρικό dashboard
- Καθολική αναζήτηση
- Βλαβολόγιο
- Πελατολόγιο
- Μηχανήματα και ιστορικό
- Εργασίες / service history
- Φωτογραφίες πριν / κατά / μετά
- Εργαλεία: Superheat, Subcooling, bar/psi, kW/BTU/h, °C/°F
- Βοήθεια διάγνωσης
- Checklists με αποθήκευση
- AI Ψυκτικού ως τοπικό τεχνικό βοηθητικό module
- Τεχνική βιβλιοθήκη
- Σημειώσεις
- Υλικά / αποθήκη
- Backup / επαναφορά JSON
- Τοπική αποθήκευση στη συσκευή

## Έκδοση
- versionCode: 10
- versionName: 1.0
- applicationId: com.psyktikos.app
- compileSdk / targetSdk: 35
- minSdk: 24

## Σημαντικό
Το AI module της v1.0 είναι τοπικός βοηθός κανόνων/δεδομένων και **δεν αποτελεί σύνδεση με online AI API**.
Το project είναι οργανωμένο για τελικό Android build. Το APK πρέπει να παραχθεί σε περιβάλλον Android/Gradle που διαθέτει το Android SDK και τα απαιτούμενα dependencies.
